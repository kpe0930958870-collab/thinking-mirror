# Thinking Mirror · สมุดแบบฝึกคิด

ต้นแบบนวัตกรรมทางการศึกษา: ครู AI ที่ไม่ยอมบอกคำตอบ แต่ถามกลับจนนักเรียนคิดออกเอง
และแสดงร่องรอยการคิดของนักเรียนทุกคนให้ครูเห็น

## วิธีใช้งาน

1. เปิดเว็บ แล้วกดปุ่ม **"ยังไม่ได้ใส่คีย์ AI"** มุมขวาบน
2. วาง Gemini API Key (ขอได้ที่ https://aistudio.google.com/apikey)
3. กด **ทดสอบคีย์** ระบบจะโหลดรายชื่อโมเดลและเลือกรุ่นที่เหมาะให้อัตโนมัติ แล้วกด **บันทึก**
4. ใส่ชื่อที่หน้าปกสมุด แล้วเริ่มทำโจทย์ได้เลย
5. กดแท็บ **สมุดครู** เพื่อดูผลการคิดของห้อง (กด "โหลดข้อมูลตัวอย่าง" เพื่อสาธิต)

ถ้าไม่ใส่คีย์ ระบบจะใช้คำใบ้สำเร็จรูปที่เขียนไว้ล่วงหน้าแทน

## ความปลอดภัยของ API Key

- คีย์ถูกเก็บไว้ใน localStorage ของเบราว์เซอร์เครื่องที่กรอกเท่านั้น **ไม่ได้อยู่ในโค้ดบน GitHub**
- ห้ามแก้โค้ดเพื่อใส่คีย์ลงในไฟล์ แล้วอัปขึ้น GitHub
- ถ้าให้นักเรียนใช้เครื่องร่วมกัน ควรจำกัดคีย์ใน Google Cloud Console
  (APIs & Services → Credentials → เลือกคีย์ → Website restrictions → ใส่ `https://ชื่อผู้ใช้.github.io/*`)

## ข้อจำกัดของต้นแบบ

- ข้อมูลการคิดเก็บในเบราว์เซอร์ของแต่ละเครื่อง สมุดครูจึงเห็นเฉพาะข้อมูลในเครื่องนั้น
- ขั้นต่อไป: ส่งข้อมูลไปเก็บรวมที่ Google Sheets ผ่าน Apps Script เพื่อให้ครูเห็นทั้งห้อง
